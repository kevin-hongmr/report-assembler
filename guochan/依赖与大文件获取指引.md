# 依赖与大文件获取指引

本仓库**只收录源码**（可通过 git 克隆即得）。运行所需的大体积文件（便携 LibreOffice、离线依赖 wheel、
构建产物）体积大且可重新生成，已列入 `.gitignore` **不入库**。本文说明这些文件**在哪下载、要什么版本、
放到哪个文件夹**，按需自行补充即可。

> 如果只是要**能直接跑的包**，不需要看本文——直接去 Releases 下载：
> https://github.com/kevin-hongmr/report-assembler/releases
> - 国产系统（aarch64，飞腾/鲲鹏）：`report-assembler-aarch64-*.zip`
> - Windows 便携版：`report-assembler-windows-portable-*.zip`

---

## 1. 便携 LibreOffice（国产系统的 PDF 转换/预览引擎）

| 项 | 说明 |
|---|---|
| **要不要** | 只有**自行构建国产包**时才需要；用 Releases 里的成品包则已内置 |
| **放哪里** | 解压/组装到 **`app/libreoffice/opt/libreoffice6.4/`**（其下应有 `program/soffice`） |
| **来源** | **麒麟官方源**（archive.kylinos.cn），非 TDF 官网 |
| **版本** | **1:6.4.2-0kylin3**（`libc6 >= 2.29`，兼容麒麟 V10 SP1 的 glibc 2.31） |

**为什么不用 TDF 官网版**：TDF 官方 aarch64 版 LibreOffice 25.8.7 实测最高要求 **glibc 2.34**，
银河麒麟 V10 SP1（glibc 2.31）跑不起来（`oosplash` 报 `GLIBC_2.33 not found`）；26.8 要求更高。
故改用麒麟官方源自带的 6.4.2 作为转换引擎来源。

**获取方式（两个脚本，自动下载并组装，不装系统、免 root）**：

```bash
# 步骤 1：从麒麟源下载所需 .deb 并解包（约 200MB；需本机有 dpkg-deb 与网络）
python tools/fetch_kylin_libreoffice.py --arch aarch64 \
    --out build/lo_kylin64/debs --extract-dir build/lo_kylin64/stage --depth 1

# 步骤 2：组装成自包含便携树（补运行时缺失的 .so、修正 BRAND_BASE_DIR、生成 soffice 包装脚本）
python tools/make_portable_lo_kylin.py --stage build/lo_kylin64/stage --out app/libreoffice
```

完成后 `app/libreoffice/opt/libreoffice6.4/program/soffice` 即就位。

> 麒麟源地址（脚本内已内置，可改 `--suite`）：
> `https://archive.kylinos.cn/kylin/KYLIN-ALL/dists/10.1/{main,restricted,universe}/binary-arm64/Packages.gz`
> 具体包（`libreoffice-writer-nogui` / `libreoffice-core-nogui` / `ure` 等）由脚本解析依赖闭包自动决定。

## 2. 离线依赖 wheels（首启动免联网安装 PyQt6 等）

| 项 | 说明 |
|---|---|
| **要不要** | 只有**自行构建国产包**时才需要；用 Releases 成品包则已内置 |
| **放哪里** | 仓库根目录 **`wheels/`** |
| **版本** | PyQt6 6.7.x、PyMuPDF 1.24.x、python-docx、lxml 6.x、pip；覆盖 **Python 3.8 ~ 3.12** |
| **来源** | PyPI（脚本用 `pip download --only-binary` 拉对应架构与 Python 版本的 wheel） |

```bash
# 下载（默认 aarch64 + Python 3.8~3.12）
python tools/download_wheels.py --arch aarch64

# 校验（静态模拟 pip 选包，确认每个 Python 版本都有 lxml / PyQt6-sip）
python tools/verify_wheels.py --arch aarch64 --wheels wheels
```

x86_64 架构把 `--arch aarch64` 换成 `--arch x86_64`。

## 3. 构建国产系统专用离线包

上述两样补齐后：

```bash
python tools/build_linux_package.py --arch aarch64
# 产出：汇报汇编程序_国产系统专用_aarch64.zip
```

- wheel 目录默认取 `build/wheels/<arch>/`，也可用 `--wheels-dir wheels` 指定为根目录的 `wheels/`；
- 便携 LibreOffice 目录默认取 `app/libreoffice`，可用 `--libreoffice-dir` 指定；
- `build/`、`app/libreoffice/`、`*.zip` 均不入库，属正常。

## 4. 一图流：各文件的位置与来源

```
仓库（git，仅源码）
├── app/                       ← 源码（app/libreoffice 不入库）
│   └── libreoffice/           ← 【需自行补】麒麟源 LibreOffice 6.4.2 → 见本文 §1
├── tools/                     ← 构建/下载脚本
├── wheels/                    ← 【需自行补】离线依赖 → 见本文 §2
├── build/                     ← 【生成物，不入库】中间产物
└── 依赖与大文件获取指引.md      ← 本文
```

| 目标目录 | 来源 | 版本 | 获取命令 |
|---|---|---|---|
| `app/libreoffice/` | 麒麟官方源 | LibreOffice 6.4.2 (kylin3) | §1 两个脚本 |
| `wheels/` | PyPI | PyQt6 6.7.x 等 | `download_wheels.py` |
| 直接可用的成品包 | GitHub Releases | 见 Release 说明 | 下载解压即用 |
