# 文档汇编程序（政务版）

把多份 `.doc` / `.docx` / `.wps` 文档自动汇编成一份符合《汇编格式模板》规范的 `.docx`：
封面 + 目录 + 正文，严格满足 11 条格式要求。

## 一、运行

- 开发/调试：
  - Windows：`app\.venv\Scripts\python.exe app\main.py`
  - Linux：`app/.venv/bin/python app/main.py`
- 打包后一键运行：
  - Windows：双击 `run.bat`
  - 麒麟 / 统信：双击 `run.sh`（或 .desktop 快捷方式）

## 二、使用步骤

1. 点「添加文件」，选择若干 `.doc/.docx/.wps`（可多选）。
2. **文件名约定**：`某某单位-标题`，例如 `发改局-关于服务业发展情况的报告.doc`。
   程序自动解析出"单位"与"标题"；列表里可手动改"单位""标题"两列。
3. 填写「汇编总标题」「汇编单位（可选）」「日期」，并可设封面标题字号。
4. 选项：默认勾选「自动清除原文档落款（单位+日期）」；「每份材料另起一页」默认关（与模板连续排版一致）。
5. 点「一键汇编并保存」→ 选择输出 `.docx`。
6. 右侧实时预览。`.doc/.wps` 自动转换与预览：Windows 走 WPS COM（个人版/专业版均可），麒麟/统信走 LibreOffice 无头转换。

> 文件列表支持**拖拽排序**、上移/下移、移除。

## 三、格式规范（11 条，已逐项落实）

| 项 | 实现 |
|----|------|
| 1 输入格式 | .doc/.wps 由转换引擎预转为 .docx 后汇编（Windows 走 WPS COM，麒麟/统信走 LibreOffice）；.docx 直接汇编，其中**宏启用文档（.docm 误存为 .docx 扩展名）会自动剥离宏并规范化**，无需转换引擎 |
| 2 结构 | 封面（大标题+可选单位+底部日期）→ 目录（目  录 + 材料标题列表）→ 正文 |
| 3 材料标题 | 居中、方正小标宋简体、二号(22pt) |
| 4 正文 | 首行缩进2字符、三号(16pt)、中文仿宋_GB2312、西文宋体 |
| 5 一级标题 | 黑体、三号、首行缩进2字符 |
| 6 二级标题 | 楷体_GB2312、三号、首行缩进2字符 |
| 7 行距 | 整份固定 28.5 磅（exact） |
| 8 单位 | 各材料标题下，楷体_GB2312、三号、居中 |
| 9 落款 | 自动删除原文档末尾的单位+日期 |
| 10 页码 | 页脚 —N—，奇偶页不同（双页翻面），正文首页为第 1 页 |
| 11 页面 | A4，左右 2.7cm、上下 3cm |

## 四、依赖与注意事项

- **转换/预览引擎**：Windows 依赖 **WPS**（通过 `KWps.Application` 的 COM 自动化，个人版/专业版均可）；
  **麒麟/统信依赖 LibreOffice**（`soffice --headless` 无头转换，WPS for Linux 不支持命令行转换）。
  程序启动时会自动做一次转换能力自检。缺少对应引擎时无法处理 `.doc/.wps` 与预览，但 `.docx` 汇编仍可用。
- **旧目录清理**：早期版本曾随附 LibreOffice 运行时（`app/libreoffice/` 与 `软件/LibreOffice/`）。
  现已改为直接调用系统安装的 LibreOffice（国产系统）或 WPS（Windows），这两个随附大目录已无代码引用，
  可手动删除以释放约 2.3GB 空间。
- **字体**：依赖系统已安装 方正小标宋简体 / 仿宋_GB2312 / 楷体_GB2312 / 黑体 / 宋体。
  缺失时程序会提示，可在 `app/fonts_bundled/` 找到随附的 4 款字体并安装。
- **标题级别识别**：按字体（黑体→一级、楷体→二级）与文本模式（"一、"/"（一）"等）自动判定；
  正文按仿宋处理。

## 五、已知限制

- 源文档中的**表格**暂未特殊处理（按段落处理）；复杂图文混排建议先转 docx 后人工核对。
- 目录为标题列表（与模板一致，不含页码与引导点）；如需页码目录可后续增强。
- 预览依赖 WPS 渲染（docx 转 PDF），首次生成略慢。

## 六、先把 .doc/.wps 转成 .docx（可选，推荐批量场景）

程序"一键汇编"时遇到 `.doc/.wps` 会自动转换（Windows 走 WPS COM）。若想**先批量转好再汇编**，
可独立使用转换脚本：

- **Windows**：把 `.doc/.wps` 文件或整个文件夹直接拖到 `tools/转docx.bat` 上，松开即批量转换，
  生成的 `.docx` 输出在原位置。
- **麒麟/统信**：把文件/文件夹拖到 `tools/转docx.sh` 上，或命令行 `sh tools/转docx.sh 文件或目录`。
- **命令行通用**：`python tools/convert_to_docx.py 文件或目录 [--outdir 输出目录]`。

转换引擎：Windows 用 WPS（COM，个人版/专业版均可）；麒麟/统信用 LibreOffice 无头转换。
转换出的 `.docx` 可直接添加进汇编程序（`.docx` 汇编不依赖任何引擎）。

> 注：若 `.docx` 实为**宏启用文档**（扩展名是 `.docx`，但内部 content type 为 `macroEnabled`，
> 即 `.docm` 被误存为 `.docx`），程序会自动剥离 VBA 宏、把 contentType 改回标准 docx 后再汇编，
> 全程不依赖 WPS。独立转换脚本 `tools/convert_to_docx.py` 也会一并处理这类文件（干净 docx 自动跳过）。
