## 一、软件简介

本程序用于把多份公文汇报材料（Word / WPS 文档）自动汇编成一份排版规范、格式统一的合订本，输出为 `.docx` 文件。适用于政府机关、企事业单位的会议材料汇编场景。

**核心能力：**

- 自动识别每份材料的**标题、单位、日期**（含标题行尾的括号单位，如"（税务局）"）；
- 自动套用统一的公文格式规范（标题/单位/正文/一级标题/二级标题字体字号、行距、缩进、对齐）；
- 保留源文档的**表格、图片、自动编号**等复杂内容，且表格、图片按源格式原样呈现；
- 自动生成**封面**与**目录**（目录可自动更新页码）；
- 自动清理各材料末尾的落款（单位 + 日期）。

## 二、运行环境要求

| 项目 | Windows 便携版 | 国产系统专用版 |
| --- | --- | --- |
| 操作系统 | Windows 7 / 10 / 11（64 位） | 银河麒麟 / 统信 UOS 等国产 Linux |
| 转换引擎 | **WPS Office 专业版 / 政府版**（负责 `.doc`/`.wps` → `.docx` 及预览） | **随包内置便携版 LibreOffice**（免安装、免联网，开箱即用） |
| Python | 已内置运行环境，无需安装 | 用系统自带 `python3`；依赖 wheel 随包，首次运行本地安装 |
| 字体 | 见下方"字体说明" | 同上 |

> ⚠️ **Windows 版：WPS 必须是专业版 / 政府版。** WPS 个人版通常不支持无头命令行转换，会导致 `.doc` / `.wps` 文件无法转换、预览不可用（`.docx` 文件仍可正常汇编）。
>
> ✅ **国产系统版：无需 WPS，也无需另装 LibreOffice。** 程序在国产 Linux 上改用随包便携版 LibreOffice 完成转换与预览，完全离线、免 root。

### 字体说明

程序汇编规范使用的字体：**方正小标宋简体、仿宋_GB2312、楷体_GB2312、黑体、宋体**。

- 其中「黑体、宋体」Windows 系统自带，无需处理；
- 「方正小标宋简体、仿宋_GB2312、楷体_GB2312」多数电脑可能未安装，缺失时请安装 `app\fonts_bundled\` 目录下随附的字体（双击 `.ttf` → 点"安装"）；
- 程序启动时会在弹窗中提示缺失的字体。

### Linux / 银河麒麟 / 统信 UOS 运行说明

国产系统请使用专门的**离线版**压缩包，**按本机 CPU 架构二选一**：

| 压缩包 | 适用机器 |
| ------ | -------- |
| `汇报汇编程序_国产系统专用_aarch64.zip` | 飞腾、鲲鹏等 ARM 机器（`uname -m` 显示 `aarch64`） |
| `汇报汇编程序_国产系统专用_x86_64.zip` | 海光、兆芯、Intel/AMD 机器（`uname -m` 显示 `x86_64`） |

该包**内置全部 Python 依赖，全程不需要联网**，适合政府内网环境。

```bash
cd 程序目录
chmod +x 启动汇编程序.sh
./启动汇编程序.sh
```

说明：

- **依赖从本地安装**：随包的 `wheels/` 目录已按 Python 3.8 ~ 3.12 备齐 `PyQt6`、`python-docx`、`lxml`、`PyMuPDF` 等 wheel，
  脚本执行 `pip install --no-index --find-links=wheels` 完成离线安装，无需访问外网。
- **自动降级**：若系统没装 `python3-venv`，或 venv 内没有 pip（麒麟精简版常见），
  脚本会自动改用 `pylibs/` 目录安装 + `PYTHONPATH` 方式运行，不改动系统配置、不需要管理员权限。
- 程序内置的 `app/runtime/` 是 **Windows 专用**的 Python 运行环境，**无法在 Linux 使用**，
  因此 Linux 依赖系统 `python3`；国产系统离线包已不含该目录。
- `PyMuPDF` 为**可选**依赖，仅影响预览区渲染；装不上也不影响汇编导出。
- 若提示 `glibc 低于 2.28`：PyQt6 官方 wheel 要求 glibc ≥ 2.28，请改用系统源
  `sudo apt install python3-pyqt6 python3-docx python3-lxml` 后重新运行脚本。
- 若 PyQt6 安装成功但仍无法启动（报 `libGL`、`libxcb` 等错误），请补装图形库：
  `sudo apt install libgl1 libegl1 libxkbcommon-x11-0 libdbus-1-3 libxcb-cursor0 libxcb-icccm4 libxcb-image0 libxcb-keysyms1 libxcb-render-util0 libxcb-shape0 libxcb-xinerama0 libxcb-randr0 libxcb-xfixes0`。
- `.doc` / `.wps` 转换与预览依赖 **LibreOffice**（Linux 版）；WPS for Linux（含 WPS365）不支持命令行转换。
  **本离线包已随附兼容的便携版 LibreOffice**（麒麟官方源 6.4.2，`libc6 >= 2.29`），开箱即用、免 root。
  若便携版与本机 glibc 不兼容（启动时预检会提示 `GLIBC_x.y not found`），改装系统版即可（程序优先用系统版）：
  `sudo apt install libreoffice-writer`。**注意：TDF 官方 aarch64 版 LibreOffice 25.x 要求 glibc ≥ 2.33/2.34，
  银河麒麟 V10 SP1（glibc 2.31）无法运行**，请勿替换为该版本（详见包内《国产系统运行说明.md》第 5 节）。
  仅 `.docx` 汇编不依赖任何转换引擎。
- 若提示"解释器错误"或 `^M`，说明脚本换行符被 Windows 解压工具破坏——请用系统自带归档管理器重新解压（脚本本身为 LF 换行）。

> 完整的国产系统离线部署与排障步骤，请另行查阅包内的 `国产系统运行说明.md`。

## 三、目录结构

```
汇报汇编程序\
├── README.md                  ← 本说明文件
├── 图标.png                     ← 程序运行图标

├── 启动汇编程序.sh              ← Linux 一键启动（自动装依赖）
├── logs\                        ← 运行日志（assembler.log，自动生成）

    ├── main.py                  ← 程序入口
```

## 四、快速开始（3 步）

1. **启动**：双击 `启动汇编程序.bat`，弹出程序主窗口（启动后黑色命令窗口会自动关闭，不影响程序运行）。
2. **添加文档**：点击「添加文件」，选择要汇编的 `.doc` / `.docx` / `.wps` 文档（可多选；添加后可在列表中拖拽排序或点「上移/下移」调整顺序，双击"单位/标题"列可手动修改）。
3. **汇编**：设置好封面标题、日期后，点击「一键汇编并保存」，选择保存位置，等待完成即可。

> 完成后程序会自动打开预览，可查看成品渲染效果。

## 五、界面功能说明

### 左侧：设置区

- **待汇编文档列表**：显示已添加的文件，列"文件 / 单位 / 标题"可双击修改；按钮"添加文件 / 移除 / 上移 / 下移"用于调整顺序（顺序即汇编后材料的先后顺序）。
- **封面与目录**：
  - **汇编总标题**：填会议名称（例如"全市服务业大会"）。封面会自动在其下一段生成"汇报材料"两行大字标题。
  - **日期**：封面底部日期（如"2026年8月"）。
  - **封面标题字号(磅)**：默认 22 磅，可按需调整。
- **选项**：
  - **自动清除原文档落款**：勾选后自动删除各材料末尾的单位、日期落款（默认勾选）。
  - **每份材料另起一页**：勾选后每份材料从新的一页开始（默认勾选）。
- **格式设置**（仅对汇编后的 **目录内容、正文、一级标题、二级标题** 生效）：
  - 每一类可分别设置**字号**（初号~小五共 12 档中文字号，默认三号）与**行距**；
  - 行距可选 **固定值**（默认 28.5 磅，可改填其他磅数）或 **行距倍数**（默认 1 倍，可填 1.5 倍、2 倍等）；
  - **正文中的表格、图片保持原文档格式，不受此设置影响**（三级标题、材料标题、单位行、封面、目录标题也不受影响）；
  - 「恢复默认」按钮可一键还原为 三号 + 固定值 28.5 磅；
  - 设置自动保存到程序目录 `config.json`，下次启动自动载入。

### 右侧：预览区

- 点击「刷新预览」或汇编完成后，右侧显示成品逐页渲染图，便于核对排版。

## 六、汇编格式规范

| 元素               | 字体                 | 字号          | 对齐   | 其他                    |
| ---------------- | ------------------ | ----------- | ---- | --------------------- |
| 封面大标题            | 方正小标宋简体            | 二号（默认 22 磅） | 居中   | 会议名称 + "汇报材料"两行       |
| 材料标题             | 方正小标宋简体            | 二号          | 居中   | 不加粗                   |
| 单位行              | 楷体_GB2312          | 三号          | 居中   |                       |
| 正文               | 中文仿宋_GB2312 / 西文宋体 | 三号          | 两端对齐 | 首行缩进 2 字符，行距固定 28.5 磅 |
| 一级标题（一、二、…）      | 黑体                 | 三号          | 左对齐  | 不加粗，首行缩进 2 字符         |
| 二级标题（（一）（二）…）    | 楷体_GB2312          | 三号          | 左对齐  | 加粗，首行缩进 2 字符          |
| 三级标题（1. /（1）/①…） | 保留原文格式             | —           | —    | 不重新排版                 |
| 表格 / 图片          | 保留源格式              | —           | —    | 原样呈现                  |

> 说明：上表中 正文、一级标题、二级标题、目录内容 的**字号与行距**可在界面「格式设置」中自行调整（下表为默认值）；目录条目使用与正文一致的格式（仿宋_GB2312 三号），不含首行缩进；打开成品后可在目录处右键"更新域"自动刷新页码。

## 七、常见问题（FAQ）

**1. 启动报错"未检测到 WPS"？**  
请确认已安装 WPS Office（专业版 / 政府版）。检测机制见"第八节"。

**2. 点击汇编后 `.doc` / `.wps` 文件转换失败？**  
- **Windows**：多半是 WPS 个人版（不支持无头转换）。请改用 WPS 专业版 / 政府版。
- **Linux / 麒麟 / 统信**：转换由随包便携版 LibreOffice 完成，无需 WPS。若启动时预检提示 `GLIBC_x.y not found`，
  说明便携引擎与本机 glibc 不兼容，请改装系统版（程序会优先使用它）：`sudo apt install libreoffice-writer`。

**3. 汇编后某些字体不对（如正文变成宋体、标题变了）？**  
多半是系统缺少「仿宋_GB2312 / 楷体_GB2312 / 方正小标宋简体」等字体。请安装 `app\fonts_bundled\` 下随附字体后重启程序。

**4. 预览空白？**  
预览依赖把成品转为 PDF。
- **Windows**：依赖 WPS（专业版 / 政府版）；若为个人版或未安装，预览不可用，但 `.docx` 汇编仍可正常进行。
- **Linux / 麒麟 / 统信**：依赖随包便携版 LibreOffice，开箱即用。若汇编产物含图片或嵌入对象且预览始终空白，
  请检查 `logs/assembler.log` 中的转换报错，并确认输出磁盘剩余空间充足
  （部分国产系统 `/tmp` 容量很小，程序已改为在输出目录旁建临时工作区）。

**5. 目录页的页码需要更新？**  
在 WPS 中打开成品，右键目录 → 「更新域」→ 更新整个目录，页码会自动刷新。

**6. 汇编后正文没有首行缩进、或标题变成二号？**  
请确认使用的是最新版本程序（本版本已修复相关格式问题）。

**7. 程序异常退出 / 报错，如何排查？**  
程序所有运行日志已自动记录到 `logs\assembler.log`（含启动、WPS 检测、汇编/预览过程、异常堆栈），可打开该文件查看详细原因，或在反馈问题时附上该文件。

## 八、运行日志说明

程序启动后会自动在程序目录下创建 `logs\` 文件夹，把运行日志写入 `logs\assembler.log`：

- 记录内容包括：程序启动、WPS 检测结果、文档添加、汇编与预览的开始/完成、拖拽与上移/下移排序、各类异常与堆栈信息；
- 单个日志文件超过 2MB 自动轮转，最多保留 5 份历史日志（`assembler.log.1` 等）；
- 程序目录不可写（如放在只读盘）时，日志自动回退到系统临时目录，不影响正常使用；
- 启动时黑色命令窗口会自动关闭，如需查看运行日志，请直接打开 `logs\assembler.log`。

## 九、WPS 检测机制说明

程序按以下顺序检测电脑上是否安装了 WPS：

1. **查注册表**：读取 Windows 注册表"应用程序路径"（App Paths）里的 `wps.exe`，覆盖当前用户与所有用户的安装（含 64 位 / 32 位视图）；
2. **扫常见目录**：若注册表未命中，按常见安装路径通配查找（如 `C:\Program Files\WPS Office\office6\wps.exe`、`Kingsoft\WPS Office\...` 等，含版本号子目录）；
3. **Linux 系统**：使用 `which wps` 及常见路径（如 `/usr/bin/wps`、`/opt/kingsoft/wps-office/office6/wps`）。

**启动自检**：程序启动时除探测 WPS 位置外，还会做一次"能力自检"——用一份临时文档实际试转换一次，从而区分：

- **专业版 / 政府版**：可正常转换与预览；
- **个人版**：通常不支持无头命令行转换，程序会提示"仅 .docx 汇编可用"。

转换时程序按 **WPS COM → WPS 命令行 → Microsoft Word COM** 的顺序自动兜底，尽量保证流程不中断。
