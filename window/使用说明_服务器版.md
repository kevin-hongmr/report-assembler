# 汇报汇编程序 · 服务器版 使用说明

## 1. 这是什么

在一台 Windows 电脑上运行本程序，**同一局域网内的其他电脑用浏览器**即可使用汇编功能，
无需在每台电脑上安装。

汇编引擎与单机版**完全一致**（同一套代码），输出的封面、目录、正文格式相同。

## 2. 运行要求

| 项目 | 要求 |
| --- | --- |
| 服务器电脑 | Windows 7 / 10 / 11（64 位），本机需**已安装 WPS Office**（专业版 / 政府版） |
| 网络 | 服务器与使用者电脑在**同一局域网**内 |
| Python | **无需安装**（已内置运行环境） |

## 3. 启动

1. 把压缩包解压到服务器电脑的任意目录（路径不要含特殊字符）；
2. 双击 **`启动服务器版.bat`**；
3. 命令行窗口会显示两个地址，例如：

   ```
   本机访问：   http://127.0.0.1:8000
   局域网访问： http://192.168.5.82:8000
   ```

4. **保持该命令行窗口不要关闭**（关闭即停止服务）。

## 4. 局域网其他电脑使用

在浏览器（Edge / Chrome 等）地址栏输入上一步的**「局域网访问」地址**，例如：

```
http://192.168.5.82:8000
```

即可看到与单机版功能一致的网页界面：选择文档 → 设置封面与选项 → 开始汇编 → 下载结果。

## 5. 常见问题

**① 其他电脑打不开？**
- 确认两台电脑在同一局域网（能互相 ping 通）；
- Windows 防火墙可能拦截 8000 端口：首次启动时在弹窗中选「允许访问」；
  或手动放行：`控制面板 → Windows Defender 防火墙 → 高级设置 → 入站规则 → 新建规则 → 端口 → TCP → 8000`。

**② 想换端口？**
编辑 `启动服务器版.bat`，把 `--port 8000` 改成其他端口（如 `--port 8080`），并同步修改浏览器地址。

**③ 提示未检测到 WPS / 转换失败？**
服务器电脑必须安装 WPS（`.doc`、`.wps` 转 `.docx` 依赖它）。纯 `.docx` 文件无需转换，可直接汇编。

**④ 结果文件在哪？**
点击网页上的「下载」按钮即可保存到本机；服务器端结果临时保存在系统临时目录，**1 小时后自动清理**。

**⑤ 多人同时使用？**
汇编任务会**排队串行处理**（WPS COM 不适合并发），多人同时提交时需稍等片刻。
