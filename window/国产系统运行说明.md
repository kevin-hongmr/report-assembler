# 国产系统运行说明（银河麒麟 / 统信 UOS）

本包为**国产系统专用离线版**，适用于银河麒麟、统信 UOS 等国产 Linux 桌面系统。
**全程不需要联外网**，所有 Python 依赖已随包附带在 `wheels/` 目录内。

---

## 一、快速开始

1. 把压缩包拷贝到目标机器，右键「解压到此处」。
2. 打开终端，进入解压出的 `汇报汇编程序` 目录：

   ```bash
   cd ~/桌面/汇报汇编程序      # 路径按实际解压位置调整
   ```

3. 赋予启动脚本执行权限，然后运行：

   ```bash
   chmod +x 启动汇编程序.sh
   ./启动汇编程序.sh
   ```

4. **首次运行**会自动完成依赖安装（约 1~3 分钟，视机器性能），完成后程序窗口自动打开。
   之后再次运行即为秒开，不再重复安装。

> 如果遇到「权限不足」，在命令前加 `sudo`；如果提示「解释器错误」或出现 `^M` 字符，
> 说明压缩包在 Windows 上被解压工具破坏了换行符，请改用系统自带的归档管理器解压。

---

## 二、离线安装是怎么做的

启动脚本 `启动汇编程序.sh` 按以下顺序工作，**每一步失败都会自动降级并给出提示**：

1. **检测环境**：自动识别 Python 版本（3.8 ~ 3.12）与 CPU 架构（aarch64 / x86_64）。
2. **优先用系统已有依赖**：若系统 Python 已装齐 `python-docx / lxml / PyQt6`，直接启动，不做任何安装。
3. **离线安装（默认）**：从随包的 `wheels/` 目录安装，
   命令等价于 `pip install --no-index --find-links=wheels python-docx lxml PyQt6`。
   `wheels/` 内已按 Python 版本准备了多套 `lxml`、`PyQt6-sip`，pip 会自动挑与本机匹配的那一套。
4. **联网安装（仅兜底）**：只有当 `wheels/` 缺失或全部不匹配时才尝试联网，
   内网环境会连接失败，这属于正常现象，脚本会继续给出离线处理指引。

运行环境也会自动二选一：

- **A 方案**：创建 `.venv` 虚拟环境（推荐，与系统环境隔离）；
- **B 方案**：若系统没装 `python3-venv`，或 venv 里没有 pip（麒麟精简版常见），
  则自动改用 `pylibs/` 目录安装 + `PYTHONPATH` 方式运行，**不改动系统任何配置，也不需要管理员权限**。

## 三、依赖说明

| 包 | 是否必需 | 用途 | 缺失后果 |
|---|---|---|---|
| PyQt6 | 必需 | 图形界面 | 无法启动 |
| python-docx | 必需 | 读写 Word 文档 | 无法启动 |
| lxml | 必需 | XML 处理（被 python-docx 依赖） | 无法启动 |
| PyMuPDF | 可选 | 预览区渲染 PDF 为图片 | 仅预览不可用，**汇编导出不受影响** |

## 四、常见问题与处理

### 1. 提示「glibc 低于 2.28」

PyQt6 官方在 Linux 上只提供 `manylinux_2_28` 版本的安装包，要求系统 glibc ≥ 2.28。
先确认版本：

```bash
ldd --version | head -1
```

若确实低于 2.28，请改用系统软件源安装（需能访问内网软件源）：

```bash
sudo apt install python3-pyqt6 python3-docx python3-lxml
```

装好后**重新执行启动脚本**，脚本会自动识别系统已装依赖，不再尝试联网。

### 2. 提示「wheels 为 xxx 架构，与本机不匹配」

本程序提供两个离线包版本，请**按本机 CPU 架构选用**：

| 压缩包 | 适用机器 | `uname -m` 输出 |
| ------ | -------- | --------------- |
| `汇报汇编程序_国产系统专用_aarch64.zip` | 飞腾、鲲鹏等 ARM 机器 | `aarch64` |
| `汇报汇编程序_国产系统专用_x86_64.zip` | 海光、兆芯、Intel/AMD 机器 | `x86_64` |

用以下命令确认本机架构：

```bash
uname -m
```

若拿到的包与本机架构不符，请换用另一个版本，离线安装才能生效。

### 3. PyQt6 装上了但启动时报 "Could not load the Qt platform plugin xcb"

缺少 Qt 运行所需的系统图形库：

```bash
sudo apt install libgl1 libegl1 libxkbcommon-x11-0 libdbus-1-3 \
                 libxcb-icccm4 libxcb-image0 libxcb-keysyms1 \
                 libxcb-render-util0 libxcb-shape0 libxcb-xinerama0 \
                 libxcb-cursor0 libxcb-randr0 libxcb-xfixes0
```

### 4. 程序能启动，但提示缺少字体

程序需要方正小标宋简体、仿宋_GB2312、楷体_GB2312、黑体、宋体。
字体已随包附带，拷贝到系统字体目录即可：

```bash
sudo cp 字体包/*.ttf /usr/share/fonts/
sudo fc-cache -fv
```

### 5. 文档转换失败 / 预览不出来

本程序调用 **WPS** 完成 `.doc/.wps` 转换与 PDF 导出，麒麟系统通常自带。
若提示找不到 WPS，需安装 WPS **专业版或政府版**（个人版不支持命令行无头转换）。

### 6. 想查看详细错误

日志目录 `logs/` 下按日期记录了完整运行过程，把它提供给技术支持即可。

## 五、目录结构

```
汇报汇编程序/
├── 启动汇编程序.sh        # 一键启动脚本（离线优先安装 + 逐级降级）
├── 图标.png
├── README.md            # 功能与操作说明
├── 国产系统运行说明.md     # 本文件
├── requirements.txt
├── app/                   # 程序代码
│   ├── main.py
│   ├── core/              # 汇编、转换、预览、日志
│   ├── ui/                # 图形界面
│   └── fonts_bundled/     # 随包字体（含 SimSun.ttf）
├── 字体包/                 # 字体源文件，供手动安装到系统
└── wheels/                # 离线依赖包（首次运行自动安装，无需联网）
```

> 说明：`app/runtime`（Windows 版 Python）与 `app/libreoffice` 均未包含在本包内——
> 前者在 Linux 上无法执行，后者本程序不使用（文档转换走 WPS）。
