# 跨平台打包与一键运行说明

目标：在 **Windows / 麒麟(x86_64·aarch64) / 统信(x86_64·aarch64)** 上一键运行，
带交互界面与预览界面。

## 关键约束：CPU 架构

麒麟/统信同时运行在 x86_64（海光/兆芯）与 aarch64（飞腾/鲲鹏）上。
LibreOffice 便携版与 Python 二进制均**按架构不同**，因此 Linux 侧需分别出包。

## 一、Windows

1. 在已装好依赖的 venv 中：
   ```
   app\.venv\Scripts\python.exe -m pip install pyinstaller
   app\.venv\Scripts\pyinstaller --noconfirm --windowed --name 文档汇编 ^
     --add-data "app\fonts_bundled;app/fonts_bundled" ^
     --add-data "字体包;字体包" ^
     app\main.py
   ```
2. 将 LibreOffice 便携版（Windows 版）解压到 `dist\文档汇编\libreoffice\`。
3. 产出 `dist\文档汇编\文档汇编.exe`，双击即运行；`run.bat` 亦可直接用 venv 启动。

## 二、麒麟 / 统信（分架构出绿色包）

对 **x86_64** 与 **aarch64** 各做一份：

1. 在对应架构的 Linux 机器（或容器）上建 venv 并装依赖：
   ```
   python3 -m venv app/.venv
   app/.venv/bin/python -m pip install -r requirements.txt
   ```
2. 放入对应架构的 LibreOffice 便携版到 `app/libreoffice/`
   （下载地址：https://www.libreoffice.org/download/portable-versions/ ，选对应架构的 AppImage/压缩包，
   解压后确保 `app/libreoffice/program/soffice` 存在）。
3. 用 PyInstaller 打包（或保留 venv + `run.sh` 直接启动）：
   ```
   app/.venv/bin/python -m pip install pyinstaller
   app/.venv/bin/python -m pyinstaller --noconfirm --windowed --name 文档汇编 \
     --add-data "app/fonts_bundled:app/fonts_bundled" app/main.py
   ```
4. 目录结构（绿色包）：
   ```
   文档汇编_麒麟_x86_64/
     ├─ run.sh            # 一键启动（nohup 后台亦可）
     ├─ 文档汇编.desktop   # 桌面快捷方式（可选）
     ├─ app/
     │   ├─ .venv/        # Python + 依赖
     │   ├─ main.py
     │   ├─ fonts_bundled/
     │   └─ libreoffice/  # 对应架构便携版
     └─ 字体包/
   ```
5. 双击 `run.sh`（或 .desktop）即运行，**无需 root**。

## 三、run.sh 示例

```bash
#!/bin/bash
cd "$(dirname "$0")"
export PYTHONPATH="$PWD/app:$PYTHONPATH"
app/.venv/bin/python app/main.py
```

## 四、字体随附

`app/fonts_bundled/` 已含 方正小标宋简体 / 仿宋_GB2312 / 楷体_GB2312 / 黑体 四款。
程序仅在系统缺失时提示用户安装；成品文档始终按规范写入字体名。
西文「宋体(SimSun)」通常系统自带，若缺失请另行安装。
